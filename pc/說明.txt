無線投屏（電腦 + 手機）— 背景常駐版
================================

【電腦端：後台（日常行呢個）】
  已裝好：開機自動啟動（Windows 工作排程器「無線投屏-後台」）→ 完全冇視窗、冇工作列圖示。
  佢一直聽手機指令，所以手機撳一下大掣就投屏 —— 電腦唔需要開任何程式。

  關掉後台：
    - 桌面／開始功能表「關閉無線投屏後台」（即 AndroidCast.exe --quit）
    - 或雙擊 C:\Users\s1215\android-cast\關閉後台.bat
    - 或 cmd 打：C:\Users\s1215\android-cast\AndroidCast.exe --quit
  再開返（即時）：schtasks /run /tn "無線投屏-後台"
  記錄檔：C:\Users\s1215\android-cast\bg.log（有問題睇呢個）

【投屏窗位置（自動判斷直／橫屏，即時搬位）】
  直屏 → 自動開喺「豎屏副螢幕」全屏（實測 2560,0 1080x1920 = DISPLAY2）。
  橫屏 → 自動開喺「主螢幕」全屏（主螢幕係橫放，實測 0,0 2048x1152 = DISPLAY1）。
  投屏期間手機一轉向 → **即時搬位，唔會重開 scrcpy、唔會黑一下**（實測 0.35～2.8 秒內到位，
  scrcpy PID 全程不變），所以一轉橫屏就即刻睇到。
  APK 有「橫屏自動搬去主螢幕」選項，唔想要可以取消剔（會即時通知電腦 + 記住）。
  「夾手機解析度」= 9:16 填滿：投屏時叫手機改用螢幕嘅比例排版（1080x2400 → 1080x1920）
  **＋同時按比例改 density（450 → 360）**，令「每 dp 高度」保持 853dp 不變 →
  桌面／App 排版一啲都唔會亂、icon 位置同原本一樣（實測同 9:20 桌面逐格對比一樣）。
  停止投屏會 `wm size reset` + `wm density reset` 還原返 9:20。
  「填滿螢幕」= 唔改手機、直接裁切到同螢幕同比例 —— 而家兩邊比例一樣時會自動略過。

【電腦關機（由手機叫電腦關機）】
  - 電腦端「投屏選項 → 允許手機關機」要剔（預設剔），設定寫入 settings.txt 會記住。
  - 手機 App 紅色「電腦關機」掣 → 撳一下會問你確定 → 電腦 60 秒後關機（有 60 秒緩衝）。
  - 長按嗰粒掣 = 叫電腦即刻取消關機；喺電腦打 shutdown /a 都得。
  - 手機 App 有「顯示『電腦關機』掣」選項，唔想要可以取消剔（會記住）。
  - 電腦剔走權限時：/ping 會回 shutdown=off，手機嗰粒掣會變灰寫「電腦未允許關機」。

【鼠標／鍵盤控制手機】
  預設係 SDK 模式 —— 鼠標唔會被鎖死：平時照用你嘅桌面，鼠標移入投屏窗
  撳／拖就等於手機上嘅撳／滑，隨時移出去都冇問題。
  對應：左鍵=撳、拖=滑、右鍵=返回、中鍵=Home、滾輪=捲動、直接打字=輸入。
  ⚠ 但小米要先開「開發者選項 → USB 偵錯（安全設定）」+ 重啟手機，
    否則 adb 唔准注入輸入事件（scrcpy 只可以睇，控制會冇反應）。
    開咗之後 adb 亦可以 pm grant，App 就能自動開無線偵錯。
  另外「投屏選項 → 鼠標鎖定」剔咗會用 UHID 相對鼠標模式（可拖住移動手機游標），
  但嗰種模式會鎖住鼠標，要按左 Alt（或 Win 鍵）放返出嚟 —— 唔需要就唔好剔。

【電腦端：有介面版（間中要配對／轉無線時用）】
  雙擊 C:\Users\s1215\android-cast\無線投屏.exe
    - 第一次配對：按「① 產生 QR 碼」→ 手機 開發者選項 → 無線偵測
                   → 使用 QR 碼配對裝置 → 掃電腦螢幕上個碼
    - 有 USB 線：插線 → 按「USB 轉無線」→ 見到可拔線就拔，之後永久免輸入

【電腦音量（由手機調）】
  - APK 下面有「電腦音量」：拖滑桿即時調 0～100%，左邊「靜音／開聲」掣可以切換。
  - 電腦端用 Windows 核心音訊 API（IAudioEndpointVolume）直接設音量，係精準百分比；
    如果核心 API 唔通會自動退回模擬音量鍵，功能唔會失效。
  - App 每 5 秒同步一次（你喺電腦改咗音量，手機滑桿都會跟住郁）。
  - 亦可以用 adb／自動化觸發：--es do volup / voldown / mute

【手機端】一鍵投屏 APK v1.7
  - 開 App → 撳中間大掣 → 電腦自動開 scrcpy（直屏落豎屏螢幕、橫屏落主螢幕）
  - 長按大掣 = 停止投屏
  - 兩個選項：「顯示『電腦關機』掣」、「橫屏自動搬去主螢幕」（即時通知電腦 + 記住設定）
  - 「電腦音量」滑桿 + 靜音掣（調電腦音量，數值即時同步）
  - **手機排版揀「9:20 原裝」或「9:16 填滿」**（下次投屏生效，即時通知電腦 + 記住）：
      9:16 填滿 = 投屏時叫手機改用螢幕比例排版 → 填滿螢幕、狀態列同底部 dock 都睇得齊（電腦端叫「夾手機解析度」）
      9:20 原裝 = 唔改手機，完整睇到手機上下（螢幕上下／左右會有黑邊，但一件都唔會切走）
  - 紅色「電腦關機」掣（撳一下問確定、長按 = 取消關機）
  - 下拉快捷面板 → 編輯 → 加「一鍵投屏」磚（真正一拉一按）

注意
----
- 手機同電腦要連同一個 Wi-Fi
- 手機「無線偵錯」熄咗（例如重開機後）→ 要手動開返一次；
  開咗「USB 偵錯（安全設定）」之後就可以 adb grant 權限自動開
- 更新 APK：可以直接 adb install（「透過 USB 安裝」已開）
- 測試橫屏要用支援橫屏嘅 App（桌面會鎖直屏）：
  adb shell settings put system accelerometer_rotation 0; adb shell settings put system user_rotation 1
  測完記得還原（accelerometer_rotation 1）
